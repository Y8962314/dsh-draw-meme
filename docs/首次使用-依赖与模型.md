# 首次使用：依赖和模型是怎么自己装上的

写给我们这一群的（别的鱼接手这个插件的时候看这份，别去翻源码）。

## 一句话

装完不用管。第一次出图它会自己 `pip install` 缺的包、自己下底模；之后就只剩推理。
但你得知道它**装到哪、下到哪、卡住了怎么办**，不然报错的时候会以为是插件坏了。

## 第一次出图会发生什么

按顺序：

1. 检查这几个模块在不在：`torch` `diffusers` `accelerate` `PIL` `numpy` `safetensors` `peft`
2. 缺哪个就 `pip install` 哪个（缺 pip 会先跑一次 `ensurepip`）
3. 底模没指定的话，从 `hf-mirror.com` 下 `cagliostrolab/animagine-xl-4.0`（约 7G）
4. 加载模型（第一次 40~60 秒，之后每次出图也是这个数，因为每次都是新进程）
5. 出图：832×832 / 28 步，显卡 8~10 秒一张，CPU 1~2 分钟
6. 压暗 0.96 → 贴中文 → 存图

**第一次最久的是第 3 步**（有时候第 2 步装 torch 也要几分钟，2.5G）。慢的时候十几分钟都正常。
别在下模型的时候以为它死了 —— `~/.dsh/draw-meme/hf/` 里的文件会一直变大，那就是在动。

## 依赖装到哪了

**装进「运行这个插件的那一个 Python」**，不是插件自带的 venv，也不是系统全局。

哪个 Python 在跑？按这个顺序找：

1. `~/.dsh/draw-meme.json` 里写的 `python`
2. 环境变量 `DSH_PYTHON`
3. `%LOCALAPPDATA%\Programs\Python\Python31x\python.exe`
4. `%APPDATA%\uv\python\cpython-*\python.exe`
5. `C:/Python31x/python.exe`
6. PATH 里的 `python` / `python3` / `py`

**Windows 应用商店那个 `WindowsApps\python.exe` 会被跳过**（一跑就弹商店），不用担心选错。

所以：想用哪个解释器，就在配置里写死 `python` 那一项，最省事。

## 模型下到哪了

- 底模缓存：`~/.dsh/draw-meme/hf/`（HuggingFace 的 cache 结构，删了就得重下）
- LoRA：插件自带的 `models/dafeiyu_v24.safetensors`（456M，不用下）

想用本地现成的底模（比如 ComfyUI 里已经有一份），在配置里把 `base` 写成那个 `.safetensors`
的绝对路径就行，脚本会读文件头判断是 SDXL 还是 SD1.5，不会再去网上拉。

## 出图存到哪了

1. 先写到「能写的目录」：优先 `~/.dsh/meme-packs/dafeiyu-auto/memes/auto/`
2. 写不进去就自动退到插件自己的 `out/` 目录（下文有原因）
3. 最后宿主进程再把它搬回表情库

所以返回的路径一定是真实存在的那个，跟着路径走就是了。

## 常见故障对照表

| 症状 | 原因 | 怎么办 |
|---|---|---|
| `No usable temporary directory found` | 沙箱里 `TEMP` 是 `/tmp` 这种 POSIX 路径，Python 不认 | 已经脚本里自己挑了可写目录；还报就是那台机所有临时目录都写不了，手动设 `TMPDIR` |
| `Permission denied: ...meme-packs...png` | 那个目录对子进程只读（有些机器 `~/.dsh` 是 RX ACL） | 已经会自动退到 `out/`；想进库就把图库目录的可写权限放开 |
| `PEFT backend is required` | 没装 `peft`，LoRA 被静默跳过，图完全不像大肥鱼 | `pip install peft`，或者让它自己装 |
| 整张图发灰发紫 | SDXL 的 VAE 在 fp16 下解码溢出 | 脚本里已经 `force_upcast`；别手动 `.to(float32)`，会报 `Input type Half and bias float` |
| 底色/画风跟 ComfyUI 对不上 | 采样器不是 `euler_ancestral` | 脚本已经对齐；自己改的话记住这个 |
| 出来的全是面瘫 / 皮肤变黑 | 提示词超过 77 token 被截断 | 把「背景、肤色、表情」放最前面，角色段压到最后 |
| 出一堆角色 / 九宫格 | 负面压不住 LoRA 的多角色倾向 | 负面加 `(multiple girls:1.6), (multiple views:1.4), (grid:1.4), (collage:1.4)` |
| `pip install` 卡好几分钟没反应 | **不是 pip 坏了**：它每次装包前会自检新版本，去拉 `pypi.org/simple/pip/`（几 MB 的索引页），网络一般就卡住 | 插件已经内置 `PIP_DISABLE_PIP_VERSION_CHECK=1`；手动装包也加这个环境变量，实测从「卡死」变 4 秒 |

## 想自己控制的话

配置文件 `~/.dsh/draw-meme.json`，设置页「表情包绘制」里也能改（改完立刻生效，不用重启）：

```json
{
  "python": "C:/Python312/python.exe",
  "base": "D:/models/animagine-xl-4.0.safetensors",
  "lora": "",
  "size": 832,
  "dim": 0.96,
  "seed": null
}
```

- `python` 留空 = 自动找
- `base` 留空 = 下 animagine-xl-4.0
- `lora` 留空 = 用内置的大肥鱼 v24
- `seed` 填了就一直复现同一张（验收那批是 51001~51020）

## 换一台新机器的最小条件

1. 有 DSH（能装插件）
2. 有 Python 3.10+（最好是 3.11/3.12）
3. 能出网（`pypi` 和 `hf-mirror.com`）
4. 硬盘留 10G（7G 底模 + 2.5G torch + 余量）。注意这是**硬盘**，不是显存
5. 有显卡最舒服；没显卡也能跑，只是慢
   - N 卡（CUDA）开箱能用
   - A 卡在 Windows 上要自己折腾：RX 6000 这一代（gfx1031）AMD 官方不支持，
     社区 ROCm 构建能跑
   - 显存这一项单独看：跑图约 6.5G，8G 卡够

满足这五条，装完直接说「画一张笑的」就行。

## 出图速度：为什么是 8 秒，不是 60 秒

插件会常驻一个出图进程（`python/worker.py`），**模型只加载一次**，之后每张只算采样。

| 情况 | 耗时 |
|---|---|
| 第一次出图（要加载 6.9G 底模） | 约 50 秒 |
| 之后每次（模型已在显存） | **8~30 秒** |
| 空闲 12 分钟没人用 | 自动退出，把 6.6G 显存还回去 |
| 下次再调用 | 自动重新起，又是第一次的 50 秒 |

**别手动去杀这个 python 进程。** 它被杀了不会报错，但下一次出图要重新加载，
你会觉得「怎么忽然又变慢了」。

如果它真的崩了（比如显存被别人抢了），宿主会发现并**自动退回「一进程一张」的老路**，
慢一点但图照样能出，不会卡死。

怎么确认它在跑：任务管理器里会有一个 python.exe，命令行带 `worker.py`。

## 出图不稳定是正常的（重要）

为了把单张压到 4 秒左右，模型跑得很紧，**废片是常态**：

- 约 6% 会出现两只大肥鱼（训练集里拼图表情包太多）
- 约 10% 图上会冒出假汉字乱码
- 约 4% 画得明显不对

**建议一次出 2~3 张挑一张用**，别只出 1 张就判断好坏。

## 怎么装这个大肥鱼 LoRA

仓库里**不带**这个权重（456M，超过 GitHub 单文件限制），要走 Releases：

1. 打开仓库的 **Releases** 页
2. 下载 `dafeiyu_v24.zip`
3. 解压出 `dafeiyu_v24.safetensors`
4. 放到插件目录的 `models\` 下，变成：

```
...
ode_modules\dsh-draw-meme\models\dafeiyu_v24.safetensors
```

5. 重启 DSH

放对了，出图日志会有一行 `loading LoRA dafeiyu_v24.safetensors ...`；
没放对会打印「警告：没找到大肥鱼 LoRA」——插件照样出图，但画的不是大肥鱼。

## 底模从哪来

`animagine-xl-4.0`，6.5G，管「会不会画」的那部分能力。

**不配也行**：首次出图会自动从 `hf-mirror.com` 下载，缓存在 `~/.dsh/draw-meme/hf/`，
第一次会卡在下载上，下完就不再联网。

**已经有本地文件**：填绝对路径最省事。

```json
{ "base": "D:/ComfyUI/models/checkpoints/animagine-xl-4.0.safetensors" }
```

**下载老断**：手动下 `animagine-xl-4.0.safetensors`，再按上面配路径。

换别的 SDXL 也能跑，但画风会变——LoRA 是相对 animagine 训的。
