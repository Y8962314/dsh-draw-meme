# 干净环境安装自检清单

给「换一台机器 / 新开一个工作区」的人用。照着走一遍，每一步都有明确的预期，
不通过就停在那一格，别往下跳。

**目标**：证明「只有 DSH + Python」的机器能一次装上并出图。

---

## 0. 前置检查

```powershell
python -V                 # 要 3.10 以上，3.11/3.12 最稳
python -m pip --version   # 有 pip；没有就先 python -m ensurepip
```

- [ ] Python 版本 ≥ 3.10
- [ ] 能访问 `pypi.org`（或国内镜像）和 `hf-mirror.com`
- [ ] 硬盘剩 ≥ 12G（底模 7G + torch 2.5G + 余量）

---

## 1. 建一个干净的解释器（模拟新机器）

```powershell
python -m venv D:\clean-test\venv
D:\clean-test\venv\Scripts\python.exe -V
```

- [ ] venv 建出来了
- [ ] 这个 venv 里 `import torch` 会失败（说明它是干净的）

---

## 2. 放插件

把 `dsh-draw-meme` 整个目录复制到
`~/.dsh/profiles/<profile>/node_modules/dsh-draw-meme/`

- [ ] `models/dafeiyu_v24.safetensors`（456M）在里面（走 LFS 或 Release 下载的话手动放进去）

---

## 3. 注册

改 `~/.dsh/profiles/<profile>/package.json`：

- [ ] `dependencies` 加 `"dsh-draw-meme": "file:<插件绝对路径>"`
- [ ] `dsh.profile.bundles` 加 `"dsh-draw-meme"`
- [ ] 改之前备份过

---

## 4. 指到干净解释器

写 `~/.dsh/draw-meme.json`：

```json
{
  "python": "D:/clean-test/venv/Scripts/python.exe",
  "base": "本机那份 animagine-xl-4.0.safetensors 的绝对路径"
}
```

`base` 指本地文件是为了先跳过 7G 下载，只测依赖安装。

- [ ] 配置文件写好了

## 5. 重启 DSH

- [ ] 重启完，工具表里能看到 `draw_meme`
- [ ] 设置页最下面能看到「表情包绘制」（要刷新页面）

## 6. 第一次出图（关键）

对它说一句：「画一张笑的，配文『笑死我了』」

**预期时间线**：

| 阶段 | 预期 | 说明 |
|---|---|---|
| 检测缺依赖 | 秒级 | 会打印「缺依赖：torch, diffusers, ...」 |
| `pip install` | 3~10 分钟 | torch 2.5G，看网速。**装了 `PIP_DISABLE_PIP_VERSION_CHECK=1` 之后不该卡死在几秒不动** |
| 加载模型 | 40~60 秒 | 第一次 |
| 出图 | 约 4~8 秒 | 纯 txt2img + embedding 拼接 |
| 总计 | 约 5~15 分钟（首次装依赖占大头） | |

- [ ] 依赖自动装上了（没手动 pip）
- [ ] 图出来了
- [ ] 图上中文是正的（不是 `鐀夏墠涓嶆檽` 那种乱码）
- [ ] 背景接近纯白
- [ ] 人物是大肥鱼（蓝发渐变、蓝瞳、女仆装、鲸尾）

**卡住怎么办**：

| 症状 | 原因 | 处理 |
|---|---|---|
| `pip` 几分钟没动静 | 版本自检在拉 `/simple/pip/` | 插件已内置关闭；手动装包要自己加 `PIP_DISABLE_PIP_VERSION_CHECK=1` |
| `No usable temporary directory` | 沙箱的 TEMP 是 `/tmp` | 插件会自己挑可写目录；还报就手动设 `TMPDIR` |
| `Permission denied ...meme-packs` | 目录对子进程只读 | 图会自动落到插件 `out/`，不影响出图 |
| `No module named 'peft'` | 依赖没装全 | 重跑一次；或手动 `pip install peft` |
| 图发灰发紫 | SDXL VAE 溢出 | 插件已 `force_upcast` |

---

## 7. 第二次出图（验证常驻进程）

马上再说一句：「画一张鼓腮的」

- [ ] **这次只花 8~30 秒**（没有重新加载模型）
- [ ] 任务管理器里有一个 `python.exe` 命令行带 `worker.py`

**如果第二次还是 60 秒以上**：说明常驻进程没起来，退回了一进程一张的老路。
查：设置页里的 python 路径对不对、`worker.py` 在不在插件 `python/` 里。

---

## 8. 收尾

- [ ] 等 12 分钟不调用，确认那个 `worker.py` 进程自己退了（显存还回去）
- [ ] 再调用一次，确认它能自动重新起来

**全部打勾 = 这个插件在干净环境能装能用。**
有任何一格没打勾，把那一格的报错原文记下来再提交。
