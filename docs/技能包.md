# 大肥鱼表情包 · 工作流技能包

## 这个工作流干什么
出一张「大肥鱼」鲸鱼娘的表情包底图：纯白背景、chibi 头身、半身构图（cowboy shot）、表情夸张。

## 用之前必须确认
1. 底模 `animagine-xl-4.0.safetensors` 在 `models/checkpoints/`
2. LoRA `dafeiyu_v24.safetensors` 在 `models/`
3. 显存：ComfyUI 走 832×832 / 28 步这套，留 12G 比较稳（ComfyUI 自己还吃一部分）；
   插件本体（diffusers）实测是 6.5G

> 走 dsh-draw-meme 插件的话，上面这些它自己会准备（依赖和底模都自动）。
> 装到哪、下到哪、卡住怎么办，看 `首次使用-依赖与模型.md`。

## 参数怎么调
- **提示词**：结构固定成
  `(pure white background:1.2), (pale pinkish skin:1.3), (exaggerated expression:1.4), <表情动作>, cowboy shot, <角色描述>`
  - **顺序不能换**：SDXL 只吃 77 token，放后面的会被整段截掉 —— 皮肤会变黑、表情变面瘫
  - 角色描述那段**不要改**（改一头色就对不上）
  - 表情动作写夸张一点：`(exaggerated expression:1.4), 具体动作`
- **seed**：随便，同一 seed 可复现（验收那批是 51001~51020）
- **steps** 28 / **cfg** 5.5 / **sampler** euler_ancestral
- **尺寸** 832×832（要 16:9 改 832×640，但构图会变）

## 出图之后（必做两步）
1. **压暗 0.96**：除纯白像素外整图乘 0.96，背景保持 255
2. **加中文**：深藏青 (30,42,96) + 白描边，字号 0.078×宽，位置 y=0.845×高，**不扩画布不垫白块**

## 色号标准（对不上就是训练集坏了）
| 部位 | 目标 |
|---|---|
| 皮肤 | #FEEDE6 |
| 头发 | #55679F |
| 背景 | #FFFFFF 纯白 |
| 白围裙/头箍 | 白色，靠深色轮廓和背景分开 |

## 踩过的坑
- 写 `warm skin` 会更黄；写 `peach skin` 反而失效 → 颜色靠训练集，不靠词
- 整图校色会把皮肤拉灰 → 别做
- 背景压白容差 >8 会吃掉白围裙和白高光 → 容差 ≤8 且只压边缘连通区
- 加字如果垫白块，会挡住角色胸口 → 直接写在图上

## 一句话记住
颜色进模型，后期只压暗和加字。
